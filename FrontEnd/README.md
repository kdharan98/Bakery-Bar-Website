# Bakery Bar Frontend

This directory contains the frontend code for the Bakery Bar e-commerce website. The project is built using React, Vite, and Tailwind CSS.

## Project Structure

- **public/**: Contains static assets such as images and the favicon.
- **src/**: Contains the main application code, including components, pages, and utilities.
- **.env.example**: Example environment variables for the project.
- **.gitignore**: Specifies files and directories to exclude from version control.

## Getting Started

1. Install dependencies using `npm install`.
2. Start the development server with `npm run dev`.
3. Build the project for production using `npm run build`.

## Notes

- This project is currently in the setup phase. No features or pages have been implemented yet.
